# Moss 转录 WebUI

基于本地 `transcribe.cpp`（Moss-Transcribe-Diarize 模型）的轻量语音转写 Web 界面，
支持时间戳分段与说话人分离。

## 启动

```bat
run_webui.bat          :: 本机访问 http://127.0.0.1:8390
```

常用参数：`--port`、`-m/--model`（GGUF 路径，默认加载 `resources/model/` 下的模型）。
默认仅绑定 127.0.0.1；如需局域网访问请自行评估安全风险后再绑定与放行。

## 功能

### 上传与转码

- 上传任意音频/视频，自动调用本机 ffmpeg 转码为 16kHz 单声道（视频抽音轨、重采样、下混）
- 上传大文件时显示实时进度条
- 原始上传文件在转码完成后即删除，只保留回听音频（约 32KB/秒），节省磁盘
- 未安装 ffmpeg 时仅支持 16kHz 单声道 16-bit PCM WAV

### 转录结果

- 说话人分离 + 分段时间戳；结果可查看 / 复制 / 导出 TXT、SRT、JSON
- 说话人时间轴可视化每个说话人的发言区间（悬浮显示时间与置信度）
- **说话人别名**：点时间轴名字旁的 ✎ 可将「说话人 1」改为任意名字（如 Sam），
  名字、徽章、导出文本同步更新；别名保存在浏览器本地，删除任务时清理
- **时间戳精度**：结果卡片上「显示毫秒级时间戳」开关（默认秒级），
  时间列、悬浮提示与 TXT/复制导出随之切换；SRT 本身为毫秒精度
- 回听播放器：播放/暂停、圆角进度条拖拽、播放进度自动高亮对应文本并滚动跟随
- 每个转录条目行首 ▶ 键：从该段起始时间开始播放
- 点击说话人时间轴色块：跳转到对应条目并高亮（播放状态保持不变）

### 设备与设置

- 推理设备（CUDA / Vulkan / CPU）在页面内切换：无任务进行时立即重载，
  有任务进行时提示等待任务结束
- 顶栏实时显示推理设备显存占用进度条（70%/90% 变色预警）
- 设置项：时间戳粒度（分段/无）、说话人分离、KV 缓存类型（默认 auto=f16 最优）、
  CPU 线程数（仅 CPU 后端生效）、n_ctx（默认 131072，调小降低单次时长上限）

### 任务管理

- 任务队列串行执行（transcribe.cpp 0.x 限制），支持取消（保留部分结果）
- 音频超过模型单次上限（约 2.9 小时）会直接拒绝，请自行裁剪
- 模型权重放 `resources/model/`（gitignore，见目录内提示文件），换模型用 `-m` 指定路径

## 说明

- 依赖（fastapi / uvicorn / python-multipart / numpy / transcribe-cpp）已装入 `.venv`
- 任务结果保存在内存中，服务重启后清空；回听音频在 `uploads/`，随任务删除自动清理
- 接口详情见 [transcribe_cpp_api.md](transcribe_cpp_api.md)
